# Wednesday 25 November 2026 — the world in one image

A newspaper front page summing up Wednesday 25 November 2026: **48 stories, 6 regions + space, 14 fields**.

- Giant date masthead, count line, "THE DAY IN UTC" timeline strip and "THE DAY IN NUMBERS" strip.
- 3 hero panels + 10 medium panels, each with an original drawn scene: Shenzhou-24 lifts off with China's first foreign astronaut, the Flinders Island bushfire, the Thanksgiving-eve US data pile, and more.
- "WHERE IT HAPPENED" world map with region counts, a DATE CHECK box (pre-dated and not-yet stories left out), and a numbered list of the rest of the day.
- Source tags CONFIRMED / OFFICIAL / REPORTED on every card.

The program is Node 22, standard library only: it draws the page with its own PNG encoder, canvas and 5×7 bitmap font and writes `/output/entry.png` (1024×1024, deterministic).

Run it: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`
